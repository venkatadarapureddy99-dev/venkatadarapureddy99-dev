### About me

- I build **test automation and quality gates**, and I'm now focused on **testing AI systems**: LLM evaluation, hallucination checks and CI gates that stop bad AI output from shipping.
- Background in **SAP test automation** (Tricentis Tosca, certified AS1 · AS2 · TDS1 · TDS2) and **medical-device V&V** (CE-marked ECG, ISO 13485).
- Mechanical engineer: MSc, University of Sheffield. Currently doing the **Applied AI & ML** programme at **IIT Kharagpur**.
- Open to **AI QA / GenAI testing / SDET** roles.

### What I'm building

| Project | What it does |
|---|---|
| 🩺 **[MediTest-AI](https://github.com/venkatadarapureddy99-dev/meditest-ai)** | A self-hosted AI quality gate for a healthcare API. Deterministic pytest tests decide pass/fail; a local LLM (Ollama + Qwen) explains failures and suggests root causes; GitHub Actions blocks the merge when the gate fails. |
| 🔧 **[playwright-self-heal](https://github.com/venkatadarapureddy99-dev/playwright-self-heal)** | Exploring self-healing UI tests: repairing broken Playwright locators so suites survive UI changes. |
| ⚡ **[cuda-zero-to-hero](https://github.com/venkatadarapureddy99-dev/cuda-zero-to-hero)** | Learning GPU programming in public, from first kernels toward real-time vision workloads. |
